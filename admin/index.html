Masuk ke admin website

Admin ini menyimpan perubahan langsung ke repo GitHub . Masuk dengan token GitHub yang punya akses ke repo itu.

Cara membuat token
  1. Buka github.com/settings/personal-access-tokens/new (login dengan akun pemilik repo).
  2. Token name: Artivora admin. Expiration: pilih 1 tahun atau sesuai kebutuhan.
  3. Repository access: pilih Only select repositories, lalu pilih artivora-web.
  4. Permissions → Repository permissions → Contents: ubah ke Read and write.
  5. Klik Generate token, salin, lalu tempel di kolom di atas. Jangan bagikan token ini ke siapa pun.
